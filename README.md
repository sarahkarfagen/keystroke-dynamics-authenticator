# Keystroke Dynamics Authentication (KDA) — MVP

Проект системы двухфакторной аутентификации на основе **клавиатурного почерка** (поведенческой биометрии). Система анализирует уникальный ритм ввода пользователя для подтверждения его личности.

---

## Идея проекта

Клавиатурный почерк — это уникальный биометрический шаблон, основанный на привычках печати. В отличие от отпечатков пальцев, его невозможно украсть в физическом виде, и он не требует специального оборудования, кроме стандартной клавиатуры.

**Цель:** Реализовать легко интегрируемый клиентский сервис, который отличает владельца аккаунта от злоумышленника по динамике нажатия клавиш.

---

## MVP (Minimum Viable Product)

Для первой итерации проект реализуется как **Client-side приложение** (на базе TypeScript), работающее без выделенного бэкенда (данные хранятся в `localStorage`).

### Основные функции:

* **Регистрация (Enrollment):** Сбор эталонных данных (3–5 повторений ввода Email/Username).
* **Анализ паттерна:** Вычисление временных интервалов между событиями `keydown` и `keyup`.
* **Верификация:** Сравнение текущего ввода с сохраненным профилем в реальном времени.
* **Обработка ошибок:** Учет использования `Backspace` как части уникального паттерна поведения.

---

## Физико-математическое обоснование

Система базируется на измерении двух фундаментальных физических величин для каждой клавиши $k_i$:

Dwell Time ($DT$): Время удержания клавиши (интервал между нажатием и отпусканием).


$$DT_i = t_{release}(i) - t_{press}(i)$$

Flight Time ($FT$): Время полета (интервал между отпусканием одной клавиши и нажатием следующей).


$$FT_{i, i+1} = t_{press}(i+1) - t_{release}(i)$$

Алгоритм решения

Для верификации используется метрика Евклидова расстояния (или Манхэттенского расстояния) в многомерном пространстве признаков:

$$Score = \sqrt{\sum_{j=1}^{N} (x_j - \mu_j)^2}$$

Где:

$x_j$ — измеренное время в текущей сессии.

$\mu_j$ — среднее время из эталонного профиля.

Если $Score < Threshold$ (пороговое значение), доступ разрешен.

## План задач (Roadmap)

### Этап 1: Сбор и фильтрация данных

* Разработка слушателя событий клавиатуры (Precise Timer).
* Создание структуры данных для хранения таймингов (`key`, `dwell`, `flight`).
* Логика обработки спецсимволов и исправлений (опечаток).

### Этап 2: Алгоритмическое ядро

* Реализация функции расчета профиля (среднее значение + дисперсия).
* Написание функции сравнения векторов (метрика сходства).
* Экспериментальный подбор коэффициента чувствительности (Threshold).

### Этап 3: Интерфейс и интеграция

* Создание UI для регистрации почерка (Progress bar для 5 попыток).
* Реализация экрана логина с вердиктом «Match / Mismatch».
* Интеграция с `localStorage` для сохранения профилей.
* Визуальная индикация успеха/ошибки.

### Этап 4: Физический анализ

* Описать влияние частоты опроса USB-порта (Polling Rate) на погрешность измерений.
* Подготовить отчет о статистической значимости различий между "своим" и "чужим" вводом.
